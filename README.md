# 개인 노후설계 관리 웹페이지

## 프로젝트 개요

50대 초중반 사용자를 위한 **초간단 개인 노후설계 관리 웹페이지**입니다. 복잡한 금융 서비스가 아닌, 계획을 시각적으로 확인하고 숫자 변화를 체감하는 것이 핵심 목표입니다.

## 핵심 특징

- ✅ **2페이지 구성**: 대시보드 + 생활비 시뮬레이터
- ✅ **서버 불필요**: 로그인, 회원가입 없음
- ✅ **단순한 구조**: 한 파일 또는 소수 파일로 장기 유지 가능
- ✅ **의사결정 지원**: 정확성보다 감각 제공에 집중

## 주요 기능

### 페이지 1: 노후설계 대시보드
- 현재 상태 요약 (나이, 은퇴 목표, 수입/지출)
- 단계별 노후 계획 (4단계: 50~55, 56~60, 61~65, 66+)
- 자산 & 수입 요약
- 건강 & 생활 관리 체크리스트
- 메모 & 할 일 관리

### 페이지 2: 은퇴 후 생활비 시뮬레이터
- 실시간 계산: 수입/지출 입력 시 즉시 결과 반영
- 은퇴 시 예상 자산 계산
- 은퇴 후 월 사용 가능 생활비 예측
- 단순화된 계산 로직으로 방향성 제공

## 기술 스택

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage (선택사항)

## 사용 대상

- 연령: 50대 초중반
- 기술 수준: 엑셀 사용 가능 수준
- 사용 빈도: 월 1~2회 점검

## UX/UI 원칙

- 큰 글자 크기 (50대 기준)
- 정보 과다 방지
- 색상 최소화 (흑백 + 포인트 1색)
- 스크롤 허용, 클릭 최소화

## 성공 기준

- ✅ 5분 이내 현재 상태 파악 가능
- ✅ 수입 변경 시 생활비 변화 즉시 이해
- ✅ 1년 이상 유지·관리 가능
